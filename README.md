# حارس | HARIS — Arabic Scam Intelligence

نظام أمني عربي لتحليل الرسائل المشبوهة، الروابط، ولقطات الشاشة، واستخراج **بصمة الاحتيال (Scam DNA)** وتقييم درجة الاشتباه وتقديم إرشادات وقائية مباشرة.

---

## 🎯 رسالة المشروع وفلسفته
حارس ليس مجرد واجهة محادثة ذكاء اصطناعي عامة، بل أداة وعي واستخبارات أمنية سيبرانية تهدف إلى:
1. **التحليل المحلي المنضبط (Deterministic First):** استخراج المؤشرات المادية وهندسة التهديد قبل أو بالتوازي مع الذكاء الاصطناعي.
2. **بصمة الاحتيال المنظمة (Scam DNA):** تفكيك المحتوى غير المنظم إلى جينات وسمات تهديد واضحة ومحددة.
3. **درجة الاشتباه (0 - 100):** تقديم مؤشر شفاف لقوة الأدلة المرصودة وتدرج خطورتها، والامتناع التام عن ادعاء أي "احتمالية رياضية قطعية" أو نسب يقين علمية كاذبة.
4. **الفحص السلبي الآمن للروابط (Passive URL Safety):**
   > **قاعدة أمنية قطعية:** لا يقوم نظام حارس بالاتصال بالروابط، أو تتبع التحويلات (Redirects)، أو فتح صفحات الويب نهائياً. يتم التحليل بالكامل محلياً عبر تفكيك بنية الـ URL وهندسة النطاقات (Lexical & Structural Analysis).

## 🧬 مصفوفة بصمة الاحتيال (Scam DNA Taxonomy)

تعتمد النواة التحليلية لحارس تصنيفاً مركزياً وموحداً في `lib/analysis/taxonomy.ts`:

### 1. أنماط الاحتيال (Scam Types):
- `BANK_IMPERSONATION`: انتحال بنك أو مؤسسة مالية.
- `GOVERNMENT_IMPERSONATION`: انتحال جهة حكومية أو منصة رسمية (أبشر، الزكاة، القضاء).
- `DELIVERY_SCAM`: احتيال شحن وطرود بريدية بطلب رسوم وهمية.
- `FAKE_PRIZE`: جوائز ومسابقات ويانصيب وهمي.
- `JOB_SCAM`: احتيال توظيف برواتب خيالية وساعات عمل وهمية.
- `INVESTMENT_SCAM`: احتيال استثماري وعوائد مؤكدة 100%.
- `ACCOUNT_TAKEOVER`: محاولات الاستيلاء على الحسابات عبر استدراج الرموز.
- `SOCIAL_ENGINEERING`: هندسة اجتماعية وضغط نفسي.
- `PAYMENT_SCAM`: احتيال فواتير وتحويلات مشبوهة.
- `UNKNOWN`: نمط غير محدد بدقة.

### 2. جينات التهديد (Scam DNA Features):
- `urgency`: الاستعجال وضغط الوقت.
- `credential_request`: طلب معلومات حساسة وكلمات مرور وأرقام بطاقات.
- `otp_request`: طلب رمز التحقق المؤقت لمرة واحدة (مع التفريق الدقيق بين طلبه وبين التحذير الأمني من مشاركته).
- `impersonation`: انتحال الهوية والعلامات التجارية في النصوص أو النطاقات الفرعية.
- `financial_lure`: حافز مالي وجوائز وعوائد وهمية.
- `suspicious_url`: نطاقات رخيصة (.xyz, .top)، عناوين IP مباشرة، خدمات تقصير، أو بونيكود (Punycode).
- `threat_language`: لغة التهديد بتجميد الحسابات أو فرض غرامات.
- `unexpected_contact`: تواصل مفاجئ وغير متوقع عبر قنوات غير رسمية.
- `secrecy_pressure`: المطالبة بالحفاظ على السرية لعزل الضحية.
- `suspicious_payment_request`: طلب تحويل مالي أو رسوم توصيل رمزية.
- `action_pressure`: أفعال أمر ملحة للنقر الفوري على الروابط.

## ⚙️ بنية الطبقة التحليلية (Deterministic Architecture)

```
lib/analysis/
├── taxonomy.ts       # المصدر الموحد لأنماط الاحتيال ومؤشرات Scam DNA
├── normalizer.ts     # تطبيع الحروف العربية، إزالة التكرار، فك التمويه، واستخراج الروابط
├── urlAnalyzer.ts    # الفحص التقني السلبي للنطاقات، التقصي، البونيكود، وانتحال البنوك
├── signals.ts        # محرك استخراج المؤشرات القائم على فحص النوايا (Intent-Aware)
├── riskEngine.ts     # احتساب درجة الاشتباه ومصفوفة الأدلة وتوليد الإرشادات الوقائية
└── index.ts          # الواجهة الموحدة (Integration Boundary)
lib/config/
└── weights.ts        # أوزان المؤشرات وعوامل التآزر وسقوف النقاط القابلة للمعايرة
```

## 🚀 البدء والتشغيل

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل الاختبارات الآلية (26 اختبار تغطي حالات الاحتيال والحالات السلبية المشروعة):
```bash
npm run test
```

### 3. فحص الجودة والبناء:
```bash
npm run lint
npx tsc --noEmit
npm run build
```

### 4. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على [http://localhost:3000](http://localhost:3000).
